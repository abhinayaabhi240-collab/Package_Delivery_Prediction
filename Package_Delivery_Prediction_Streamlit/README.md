# Package Delivery Prediction using Streamlit

## Run
```bash
pip install -r requirements.txt
python train_model.py
streamlit run app.py
```

## Files
- app.py: Streamlit interface
- train_model.py: Model training
- data/package_delivery_data.csv: Synthetic dataset
- package_delivery_model.pkl: Trained Random Forest Regressor
- feature_importance.png: Feature chart
- requirements.txt: Dependencies

The dataset is synthetic and intended for educational use.
